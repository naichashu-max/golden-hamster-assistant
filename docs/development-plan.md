# 金丝熊饲养助手 · 开发计划

> 目标：面向普通金丝熊（叙利亚仓鼠）饲养者的本地优先宠物管理 App。
> 原则：温暖、简洁、治愈；只做饲养提醒，不做疾病诊断。

## 里程碑

### M1 · 设计与架构（本阶段）
- 产品设计：定位、用户、功能、页面、视觉规范
- 数据库设计：实体、字段、关系、SQL schema
- 项目架构：monorepo、分层、本地存储 + 云同步 + AI 服务抽象

### M2 · 工程脚手架
- 根目录统一脚本
- `client`：React + TypeScript + Vite，移动端优先
- `server`：Express + TypeScript + SQLite（预留云同步后端）

### M3 · 数据层与核心算法
- 领域类型定义
- IndexedDB 本地存储封装与仓储层
- 健康评分引擎
- 护理周期计算
- AI 陪伴规则引擎
- 云同步接口预留

### M4 · 后端 API
- 宠物档案、各类记录、健康、AI 路由
- SQLite 持久化

### M5 · 前端 UI
- 主题样式、底部导航、全局状态
- 首页：我的金丝熊 / 今日状态 / 最近照片 / 成长曲线
- 档案、成长、日常、活动、健康、AI 陪伴页面

### M6 · 彩蛋与交付
- 隐藏彩蛋「昕」
- README 与运行说明

## 交付顺序

1. 产品设计
2. 数据库设计
3. 项目架构
4. 首页 UI
5. 核心代码

每个里程碑都有可运行、可验收的产出。

# 产品设计

## 1. 一句话定位

一只温暖、简洁、治愈的金丝熊成长手账。记录它每天的吃喝、跑轮、体重与心情，
让饲养者在日常照料中获得确定感，而不是像在使用医疗软件。

## 2. 用户画像

- 养金丝熊/叙利亚仓鼠的年轻人，习惯用手机记录生活。
- 关心「它今天好不好」，但不具备兽医专业知识。
- 需要：简单记录、直观图表、温和提醒、可回看的成长相册。

## 3. 设计原则

1. **本地优先**：数据默认保存在设备本地，离线可用。
2. **云同步预留**：所有写入经过统一仓储层，未来可无缝接入云端。
3. **只提醒不诊断**：AI 与健康评分只给「饲养建议」，绝不输出疾病结论。
4. **温和的视觉**：奶油底色、柔和橘棕、大圆角、充足留白。

## 4. 功能清单

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 宠物档案 | 创建/编辑档案 | 名字、出生日、品种、性别、照片、性格 |
| 成长记录 | 每日体重/身长/状态 | 自动生成体重曲线 |
| 成长记录 | 成长相册 | 上传照片，按时间排列 |
| 日常管理 | 喂食/饮水/换垫料/洗澡 | 记录并计算距离下次护理时间 |
| 活动记录 | 夜间活动、跑轮时间、活跃度 | 生成每日报告 |
| 健康分析 | 健康评分 | 体重/食量/活跃度趋势综合打分 |
| AI 陪伴 | 对话入口 | 依据历史记录给出温和建议 |

## 5. 页面结构

底部导航 5 项 + 首页：

1. **首页**：我的金丝熊、今日状态（健康评分/体重/昨晚活动）、最近照片、成长曲线
2. **成长**：体重身长记录、曲线、成长相册
3. **日常**：喂食/饮水/换垫料/洗澡 + 下次护理倒计时
4. **活动**：夜间活动、跑轮、活跃度、每日报告
5. **健康**：评分与趋势、饲养提醒
6. **AI**：对话式陪伴入口（作为独立入口，也在首页快捷进入）

## 6. 视觉规范

- 背景：暖米白 `#FBF6EF`
- 主色：柔和橘棕 `#D98E5F`
- 强调色：蜂蜜黄 `#E9B45C`
- 文字：深可可 `#4A3728`
- 卡片：白色 + 大圆角 `20px` + 轻阴影
- 字体：系统字体，标题偏圆润；数字用等宽风格增强数据感
- 图表：柔和折线，使用主色渐变

## 7. 非目标（明确不做）

- 不做疾病诊断、用药建议、医疗结论
- 不收集/上传敏感健康数据到第三方
- 首版不做多设备实时协同
